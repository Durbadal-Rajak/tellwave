# Tellwave

Free voiceovers and royalty-free music for your videos, with a connector so Claude can
make them for you. No login, no sign-up.

- **Voiceovers**: 28 natural English voices (Kokoro, Apache-2.0), up to four speakers
  per script, adjustable speed. Runs in your browser, so the website has no usage limit.
- **Music**: an original composer with eight moods (horror, suspense, ambient, sad piano,
  lo-fi, cinematic, upbeat, mystery), 5 seconds to 5 minutes. Every track is generated
  for you, so it is free to use with no credit line.
- **Free tracks**: search real recordings and sound effects on Openverse, filtered to
  CC0 / public domain and CC BY (with the credit line ready to copy).
- **Claude connector (MCP)**: tools `list_voices`, `generate_voiceover`,
  `compose_music`, `search_music`. Claude gets a download link for each file.
- **Library**: save results on your device (nothing leaves the browser).

## Deploy on Vercel

1. Import this GitHub repository at [vercel.com/new](https://vercel.com/new).
   Framework preset: **Other**. Leave the build and output settings as they are
   (`vercel.json` sets them).
2. Before pressing Deploy, open **Environment Variables** and add:
   - `MCP_SECRET`: 16 or more random characters. Keep it private; it is the key to
     your Claude connector. (The site's Claude tab has a Create key button.)
3. Deploy, then open `https://<your-project>.vercel.app`.
   - Make a short voiceover. The first one downloads the voice model (about 90 MB)
     to your device; after that it starts right away.
   - Check the server voice: open
     `https://<your-project>.vercel.app/api/selftest?key=<MCP_SECRET>`.
     It should show `"ok": true` (the first call can take up to a minute).

Changed `MCP_SECRET` later? Redeploy so the new value is used.

**Recommended: short links for long voiceovers.** Without storage, a voiceover link
carries the whole script, so a long script makes a long link that Claude can copy
wrongly. In Vercel open **Storage → Create → Blob**, connect it to this project (it adds
`BLOB_READ_WRITE_TOKEN` for you) and redeploy. Each voiceover request then saves a
small job file and Claude gets a short link instead. Music links are always short.

## Connect to Claude

1. On claude.ai, open **Customize → Connectors**, choose **Add → Add custom connector**.
2. Name: `Tellwave`. URL: `https://<your-project>.vercel.app/mcp/<MCP_SECRET>`.
   Authentication: **No sign in**. Add.
   (Alternative: URL `https://<your-project>.vercel.app/mcp` plus a request header
   `Authorization: Bearer <MCP_SECRET>`.)
3. In a chat, press **+ → Connectors** and turn Tellwave on, then ask, for example:
   "Use Tellwave to compose a 45-second suspense track and a voiceover of this intro
   with a deep male voice."

If Claude should also download the files into its own cloud workspace (for example
to put the audio into a video it is making), allow your domain in claude.ai
**Settings → Capabilities** (allowed domains), e.g. `<your-project>.vercel.app`.

## Limits and costs

- The website renders voice and music on your phone or computer: no server cost, no
  limit.
- Claude's requests render on your Vercel server. The free Hobby plan includes
  4 active CPU-hours a month; if it runs out, Vercel pauses the project until the
  next 30-day window. Repeat downloads of the same link come from Vercel's cache.
- Vercel's Hobby plan is for personal, non-commercial use. If your channel is a
  business, check Vercel's terms or use the Pro plan.
- Claude's voiceovers take up to 2,500 characters per call (about 3 minutes), so each
  one finishes inside Vercel's 5-minute limit; Claude is told to split longer scripts.
  The website itself takes up to 5,000 characters.

## Licences

- Voices: Kokoro 82M weights are Apache-2.0. The audio you generate is yours.
- Composed music: generated by this code for each request, no samples or third-party
  recordings, so no licence fee or credit line.
- Openverse tracks: CC0 / public domain need no credit; CC BY needs the credit line
  (put it in your video description). Non-commercial and no-derivatives licences are
  filtered out.

## Privacy

No accounts and no tracking. Services involved: Vercel (hosting), Hugging Face (model
files), jsDelivr or esm.sh (voice engine code), Google Fonts (typefaces), Openverse
(track search). Your library stays in your browser. Claude's voice links contain the
script (compressed and signed) so nothing needs to be stored on a server.

## Optional settings

| variable | what it does |
| --- | --- |
| `BLOB_READ_WRITE_TOKEN` | added by Vercel when you connect a Blob store: short voiceover links |
| `OPENVERSE_CLIENT_ID`, `OPENVERSE_CLIENT_SECRET` | higher Openverse search limits |
| `PUBLIC_BASE_URL` | the address used in Claude's links (for a custom domain) |
| `MCP_ALLOWED_ORIGINS` | extra browser origins allowed to call `/mcp` |

## Develop

```bash
npm install
MCP_SECRET=dev-secret-0123456789 npm run dev   # http://127.0.0.1:3000
npm test                                       # unit + API tests
node test/e2e.mjs                              # browser tests (needs Playwright)
```

`TELLWAVE_FAKE_TTS=1` swaps the voice model for a test tone on the server, and
`?fake-tts` does the same in the browser on localhost.

Project layout: `public/` is the website (no build step), `public/js/shared/` is
code shared by the browser and the server (composer, WAV, script handling, voices),
`api/index.mjs` is the one serverless function, `lib/` holds the MCP server, signed
links, Openverse search and server-side Kokoro. Planning notes are in `replica/`.

## Troubleshooting

- **Selftest shows an error**: open Vercel → your project → Logs and look at the
  `api/index` function. The usual causes are a missing `MCP_SECRET` or the model
  download timing out on a cold start (try again).
- **Claude says the connector failed**: open the connector URL in a browser; it
  should say it is your Tellwave connector link. A 404 means the key in the URL does
  not match `MCP_SECRET`.
- **The website's voice engine won't load**: it downloads code from jsDelivr and the
  model from Hugging Face; a network filter that blocks them stops it.
